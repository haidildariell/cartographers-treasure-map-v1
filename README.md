A hand-drawn treasure map of an island that does not exist, entered in the
make.fun bounty **Charm the Cartographers: A One Day Treasure Map Sprint**.

## The map

`main.py` draws the whole map from scratch in pure Python stdlib — no
downloaded images, no third-party packages. It renders the Isle of Mislaid
Treasure: Port Last-Chance, Mount Probably-Doom, the Very Polite Volcano
(it only erupts on Tuesdays), Lake Second Breakfast, the Giggling Woods,
Crabby Cove, the Shipwreck Sandwich Bar, the Sea Monster's Day Off, and a
dotted route to X Marks the Spot (probably). A compass rose, a ship, a
kraken on his day off, and a sea serpent wearing a tiny crown fill the seas
around it.

Run it:

```sh
python3 main.py
```

It writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR`
(default `/output`).

## How it is drawn

The program is a small software rasterizer: scanline polygon fills, thick
polylines with round caps, Catmull-Rom smoothed coastlines and rivers, a
hand-made all-caps stroke font for every label, and a minimal PNG encoder
(zlib is stdlib). Everything — coastline, trees, monsters, lettering — is
generated by the code in `main.py`.
